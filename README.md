# Asistente Regulatorio Eléctrico

Local RAG chatbot for Spanish electricity regulation, built for consulting teams advising energy retailers (comercializadoras).

The assistant answers regulatory questions based on official documents (RD 88/2026, Ley 24/2013, RD 897/2017, RD 216/2014) and scraped institutional web content (CNMC, MITECO, REE), using a local vector database and the Claude API.

## Features

- **4 working modes**: Consulta regulatoria, Comunicación a clientes, Briefing interno, Plazos y deadlines
- **3 answer lengths**: Corta, Media, Detallada
- **3 precision levels**: Orientativa (conversational), Precisa (with article references), Literal (near-exact citations with [VERIFICAR] tags)
- **Confidence indicator**: Every response includes ALTO/MEDIO/BAJO confidence rating
- **Verification reminder**: Orange warning on every response reminding users to verify in official sources
- **30 verified official URLs**: BOE, CNMC, MITECO, REE, OMIE — the chatbot only references URLs from this verified list
- **Resources panel**: Side panel with all official links and ingested documents
- **Token budget tracking**: Monthly usage monitor with color-coded alerts
- **Web scraping**: Script to download institutional web content and add to the knowledge base

## Architecture

```
User question → Embedding search (ChromaDB) → Top chunks retrieved
    → Claude API (system prompt + chunks + question) → Answer with sources
```

- **Documents**: Stored locally as PDFs + scraped .txt files
- **Vector DB**: ChromaDB with sentence-transformers embeddings (all-MiniLM-L6-v2)
- **LLM**: Claude Sonnet via Anthropic API (only relevant chunks sent per query)
- **Interface**: Flask web app at localhost:5000

## Project Structure

```
├── app.py                  ← Flask server + Claude API + RAG logic
├── ingest.py               ← PDF/TXT reader, chunker, ChromaDB ingester
├── scrape_resources.py     ← Web scraper for official institutional pages
├── requirements.txt        ← Python dependencies
├── .env                    ← API key (not in repo)
├── token_usage.json        ← Monthly token tracking (auto-generated)
├── documents/              ← Source PDFs (not in repo — add your own)
│   └── scraped/            ← Scraped web content (.txt files)
├── templates/
│   └── index.html          ← Chat interface
└── chroma_db/              ← Vector database (auto-generated by ingest.py)
```

## Setup

### Prerequisites

- Python 3.10 or higher
- Anthropic API key ($5 minimum prepaid at [console.anthropic.com](https://console.anthropic.com))

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/asistente-regulatorio-electrico.git
cd asistente-regulatorio-electrico

# 2. Create virtual environment
python -m venv venv

# Windows:
.\venv\Scripts\Activate
# macOS/Linux:
source venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Create .env file with your API key
echo ANTHROPIC_API_KEY=sk-ant-your-key-here > .env
```

### Add Documents

Place your PDF documents in the `documents/` folder:

- RD 88/2026 Reglamento General de Suministro (from BOE)
- Ley 24/2013 del Sector Eléctrico (consolidated text)
- RD 897/2017 Consumidor Vulnerable y Bono Social (consolidated text)
- RD 216/2014 PVPC (consolidated text)

All documents must be publicly available regulatory texts — do not include internal or confidential company documents.

### Scrape Web Resources (optional)

```bash
python scrape_resources.py
```

Downloads content from official CNMC, MITECO, and REE pages into `documents/scraped/`.

### Ingest Documents

```bash
python ingest.py
```

Reads all PDFs and scraped .txt files, splits them into chunks, and stores them in ChromaDB.

### Run

```bash
python app.py
```

Open [http://localhost:5000](http://localhost:5000) in your browser.

## Usage

### Modes

| Mode | Purpose |
|------|---------|
| **Consulta regulatoria** | Direct Q&A about regulation with article references |
| **Comunicación a clientes** | Draft consumer-facing communications |
| **Briefing interno** | Executive summaries by department (ICT, B2C, Contracts, Payments) |
| **Plazos y deadlines** | Chronological list of deadlines and required actions |

### Precision Levels

| Level | Use case | Behavior |
|-------|----------|----------|
| **Orientativa** | Quick team discussions | Conversational language, general overview |
| **Precisa** | Internal work, reports | Specific articles, dates, figures cited |
| **Literal** | Client comms, compliance | Near-exact citations, [VERIFICAR] tags on uncertain data |

### Token Budget

The chatbot tracks monthly API usage. With $5 prepaid credits (~3M tokens):
- ~200-300 queries per month at Precisa/Media settings
- Budget resets automatically each month
- Color alerts at 50%, 75%, and 90% usage

### Updating the Knowledge Base

When new regulation is published or institutional pages are updated:

```bash
# 1. Re-scrape web content
python scrape_resources.py

# 2. Re-ingest everything
python ingest.py

# 3. Restart the chatbot
python app.py
```

## Important Disclaimers

- **This is a productivity tool, not a legal oracle.** Every answer should be verified against the original source before use in client communications or regulatory filings.
- Every response includes a confidence level (ALTO/MEDIO/BAJO) and a verification link.
- The chatbot bases its answers exclusively on the ingested documents and scraped content. It may miss information from documents not in the knowledge base.
- No internal or confidential company data is stored or processed — only publicly available regulatory texts.
